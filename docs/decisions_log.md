# 결정과 중요한 점 기록 (드래프트)

클라우드 요약 문서: 비공개 진행 기록 문서(카드 결정 기록)가 따로 있다.

대화가 길어져 맥락이 끊겨도 이어서 일할 수 있게, 담당자와 정한 것과 작업 중 알게 된 중요한 점을 모은다. 새로 정한 것이 생기면 맨 아래 "기록"에 날짜와 함께 더한다.
규칙의 정본은 CLAUDE.md와 .claude/commands/review-run.md이고, 이 문서는 "왜 그렇게 정했나"와 "아직 안 정한 것"을 남기는 곳이다.

## 1. 일하는 방식 (담당자 선호)

- 보고와 리포트는 한국어. 가운뎃점(·), "lol", "ㅋㅋㅋ", 사과 표현을 쓰지 않는다. 리포트에 가운뎃점이 있으면 기계 검사가 FAIL로 본다.
- 리뷰 원문을 보여 줄 때 요약하거나 줄이지 않고 전문을 보여 준다(정답 세트 태깅 때 담당자 지적).
- 정확도가 먼저, 속도는 원래 방식보다 빠르기만 하면 된다. 숫자는 스크립트만 만든다.
- 돈이 드는 호출은 담당자가 정할 때만. 유료 수집(amz-review scrape_reviews)은 꺼져 있다(config/pipeline.yaml paid.enabled: false).
- 결과를 보낼 때 파일 경로를 맨 앞에 적어 PC에서 바로 열 수 있게 한다.

- 선택이 나오면 웬만하면 Claude가 정해 진행하고 무엇을 골랐는지 알린다. 돈이 드는 호출(유료 수집), 밖으로 나가는 메시지, 되돌릴 수 없는 일만 담당자께 묻는다(10/7 21:23 담당자 스레드 글, 직접 받음).
- 결과물 품질이 먼저, 실행 시간 줄이기는 그다음(10/7 21:15 문답 스레드 글, 프로젝트 정리 메모로 전달받음).
- 태깅 규칙 모음의 이름은 "룰북"(10/7 20:52 문답 스레드 글, 프로젝트 정리 메모로 전달받음).

## 2. 환경과 비용

- PC는 Windows. 모델 실행은 헤드리스(claude -p, 프롬프트는 stdin, --allowedTools, gold 폴더 읽기 금지). bypassPermissions는 쓰지 않는다.
- 로그인은 Claude Max 구독(담당자가 /status로 확인, 2026-10-07 10:26 UTC). costs.jsonl의 달러는 "API 요금 환산 어림값(실제 청구 없음)"으로 적는다.
- 토큰 값은 출력하거나 파일에 쓰지 않는다. 로그인 파일(~/.claude.json)은 PC 권한 검사가 읽기를 막는다.
- 데이터는 모두 무료: 리뷰는 공유 리뷰 DB(search_reviews, get_review_stats), 상품과 시장은 spd-amz-market. 2026-10-07까지 유료 호출 0번.
